Zero-shot: switching between nearest context views

Zero-shot protocol of Table 3 (DL3DV-trained model, 16 context views selected by K-means, each frame rendered from its 4 nearest context views, GFM-estimated poses). We render 120 consecutive captured frames, so the set of nearest context views changes as the camera moves. Each video shows the RaViS rendering (left) and the ground truth (right). A red border marks frames where the nearest-context set has just changed.
