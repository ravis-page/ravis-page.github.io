Smooth camera paths with fixed context and fixed GFM predictions

For each RealEstate10K scene, the two context views and the GFM (VGGT-Ω) predictions (poses, depth, features) are computed once and kept fixed. Only the target camera moves along a 90-frame path: context 0 → a real target view with large disocclusion → context 1 (rotation slerp, linear translation). Each video shows, from left to right:
